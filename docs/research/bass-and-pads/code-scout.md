## 1. BASS today

### Voice synthesis (Liminal/Audio/Lofi/LofiBassVoice.swift)
- `enum LofiBassVoice` (l.7): `.classic` (sine + decaying 2nd harmonic + tanh, bit-for-bit legacy, attack 18 ms raised-square, release 0.31 s, gain 0.337), `.roundSub`, `.pluck`, `.longAnswer`. All mono, zero start phase, 60 ms end edge (`fade`, l.134).
- `Recipe` (l.90) + `recipe` table (l.107-122): roundSub = rise 5 ms, release 0.22 s, +30 cent glide over 35 ms, 2nd harm 0.10, drive 1.1, gain 0.2777. pluck = rise 3 ms, release 0.18, harmonics (0.12, 0.10, 0.05), bright burst 0.55 fading in 90 ms, 3 ms 1.5 kHz Hann click at 0.1, drive 1.2, gain 0.268. longAnswer = rise 12 ms, release 0.42, 2nd 0.04 + 0.12 burst (tau 0.25 s), drive 1.05, gain 0.2797.
- Renderer `addShaped` l.125: single phase-accumulating osc, raised-cosine rise/release, `tanh(drive*body)/tanh(drive)`. Mono (L=R). No filter, no sub-octave, no noise, no per-note pitch envelope other than roundSub glide. No samples: bass is pure synthesis. `LofiSampleBank` (LofiSampleBank.swift) only loads `LofiLead-<group>-<root>[-layer].wav`, mono <= 3 s, for lead/texture, never bass.
- `attackLead` (l.20) per voice: classic 8.5 ms, roundSub 1.6, pluck 1.4, longAnswer 3.8 (20 percent envelope point). `lowRiseLead(midi:)` (l.35) renders 0.5 s and measures the voice's 40-160 Hz half-amplitude rise with `LofiDrumLandmarks.lowBandRise` (Butterworth 40-160 Hz zero-phase, 2 ms RMS, -6 dB point, LofiDrumLandmarks.swift:156-190). It is called per anchored note during scoring (~20 ms synthesis) and must stay measurable for any new voice. Tests allow -5 to +40 ms.
- `LofiSynth.add` (LofiSynth.swift:7) routes `.bass` to `.classic`; legacy only (renderer uses `score.bassVoice`, LofiRenderer.swift:129).
- `LofiScore.bassVoice(seed:section:phrase:)` (LofiScore.swift:271): answer -> pluck; returnTheme and breakdown -> longAnswer; theme/variation -> roundSub, 25 percent of takes pluck (rng fork phrase/4 + 733). One voice per phrase. Test pins shares and mapping.

### Bass line writing (LofiScore.swift)
- `Harmony.bass(offset, near:)` (l.318): pitch class from scale, register MIDI 28...41 (E1 41 Hz to F2 87 Hz), nearest to `near` (default 34). `bassLine` l.434.
- Figures per section (beat, length in beats, midi, velocity): theme/variation = (0, 1.7, home, .82), (pickup 5.5|6.75|7.5, 0.55, fifth, .63), (8, 1.45, home, .80), variation adds (11.5, 0.65, motion, .67). answer = (0,1.45,5th degree,.80), (4.5,1.10,fifth,.72), (8,1.35,home,.76). returnTheme = (0,1.8,home,.85), (4,1.15,fifth,.75), (8,1.60,home,.80). breakdown = (2,1.15,motion,.76), (8,1.05,home,.73). So 2-4 notes per 16-beat phrase: roughly 1 to 1.8 beats sounding of 16. Very sparse, whole-note-ish; nothing on beats 12-16 except variation. Notes carry `send: 0` (no bass in the wet rack).
- Placement: with a timing field (take landmarks), structural accents at beat 0 and 8 look +-0.12 beats (`bassAccentWindow`, l.179) for a kick with confidence >= 0.6 (`bassAccentConfidence`, l.181), and start at `kick.lowRise - voice.lowRiseLead/beatSeconds` (so the 40-160 Hz bodies rise together). `BassAnchor` (l.146) records it. Other notes: grid beat + `pocket` (0.017-0.045 beats) + clamped timing-field lean. Legacy path (no timing): snap to a kick within 0.075 beats.
- A note running into an anchored accent is shortened so its release has faded: clearance = voice release / beatSeconds + `bassAccentClearance` 0.030 s (l.508), min length `bassShortestLength` 0.12 beats (l.510). Test asserts `beat >= 0` and `beat + length <= 16`: notes can never ring past the phrase.

### Rendering chain and levelling (LofiRenderer.swift)
- Stem buffers are exactly n = phrase frames (`stereoBuffer`, l.103): no tail, no carry into the next phrase for bass or texture dry. Notes are hard-limited to the 16 beats by score tests, and a 4 ms edge envelope (`edge`, ~l.322) fades both ends.
- Order (l.308-393): sum L+R * 0.5 to mono -> `LofiStemChains.applyBass` (LofiStemChains.swift:238) -> `headroom` soft knee (l.749; above 0.74 linear, tanh to 0.839 max) -> edge envelope -> kick duck gain -> copy to R. No send to effects, no stereo, no bus-level EQ beyond the chain. There is no per-phrase loudness scaling for bass (lead and mids are normalised per phrase, bass is not).
- `LofiStemChains.Bass` (LofiStemChains.swift:64-80): HPF 30 Hz Butterworth; parallel harmonics = asymmetric tanh (drive 4.0, bias 0.2, normalised to phrase peak, oversampled x2) -> HPF 120 Hz -> mixed at 0.20 (`saturationMix`); compressor ratio 3.5, knee 6 dB, attack 20 ms, release 150 ms, threshold = 95th percentile of 10 ms peaks minus 6 dB (`thresholdBelowReferenceDB`), makeup restores pre-compression RMS up to 4 dB (`maxMakeupDB`); EQ peak 280 Hz Q1 -2 dB, LPF 4.5 kHz; `outputTrimDB` +1 (tuned so bass 60-250 Hz sits about -5 dB under the drum bus, C-B3). Blocks of 32 frames (`blockFrames`). `dynamicsEnabled` flag gates saturation/comp/trim for tests.
- Kick duck `LofiKickDuck` (LofiSidechains.swift): depth 4 dB (`depth` 0.369 linear), attack 3 ms, release 100 ms. Landmark path (`landmarkGains`, l.78): every kick with confidence >= 0.5 (`landmarkConfidence`), gate from attackFrame to max(attack, lowRise) + 40 ms (`landmarkHold`), level = min(1, sqrt(strength/median strength)), 0.5 s preroll. Fallback level detector (HPF 35, LPF 112, slope 28, background 1.8x). Duck applies to bass only. Drums and bass are not ducked by chops (`ArchiveVoice.MusicDuck`, ArchiveVoice.swift:167 comment).
- Playback/bus: `LofiBus.bass` BufferSource goes straight into the mixer (LofiBus.swift:9,22); no fader (dry/texture/wet have faders for chop ducking). `LofiPlayback.swift:309` sets visual state `.drone` level 0.40 when a phrase has bass notes.
- Late-phrase fallback (LofiPlayback.swift:222-238): when the next phrase is not ready with < 1 s left, the previous `music` (all stems incl. bass) is repeated on the same grid with its `fallbackWet`. Any redesign must keep every stem a fixed-length n-frame buffer scheduled sample accurately and must stay cheap enough to render off the audio thread (D115 notes lowRiseLead ~20 ms per call).

## 2. CHORDS (texture/mids) today

Naming: Part `.texture` (LofiScore.swift:122) = "mids"; the stem is `phrase.texture`, bus `LofiBus.texture` / `textureFader`, solo-stems.py calls it "chords".

### Scoring (LofiScore.mids, l.~530-600; voicing l.~605)
- Shells: each "event" is TWO notes (lower + upper) from `voicing(for:previous:harmony:)`: pitches from `harmony.notes(for: root, intervals: [3, 7])` i.e. minor third and fifth only (no root, no 7th/9th), register `45...62` (A2-D4, 110-294 Hz), pair spacing 3-10 semitones, cost leaning to (49, 55), penalty below 48. `chordDegree` = 0, or the 5th degree in answer/variation phrases (`reply`, l.239).
- Articulations (`LofiScore.Articulation`, l.126): `.stab` length 0.35 beats (off-beat, needs gap >= 0.75), `.answer` length 1.6 beats (0.5/0.75/1.0 beats after a landing lead note whose next onset is >= 1.5 beats away), `.rolled` length 1.30 beats with upper note 0.17 beats late (needs gap >= 0.5). Break: at most 2 of each kind per phrase, 2-4 events per non-breakdown phrase (`rng.int(2...4)`), 0 or 1 `.answer` in breakdowns (60 percent chance, velocity 0.42).
- Hard constraints: `midOnsetClearance` 0.12 beats from every lead/ornament onset (l.~187), `midLatestEnd` 14.5 beats (shell + length <= 14.5), events keep 0.25 beats apart (`fits`), return phrase silent until `quiet` (>= 2 beats / first cell boundary). Velocity 0.50-0.66 (breakdown 0.42); `send` 0.45-0.56 stab, 0.55-0.68 rolled, 0.62-0.75 answer; `color` 0.46 stab / 0.40 others.
- Net density: 2-4 events x 2 notes, 0.35-1.6 beats each = at most ~4 to 6 beats of sound in 16, mostly in lead gaps. That is why it reads as a sparse second melody.

### Sound (LofiRenderer.swift:112-150, LofiSampleBank.swift:64)
- Texture notes are NOT a pad synth. They are played with the same sampled instrument as the lead (`samples.sample(for: score.preset, midi:, velocity:)`, piano/pluck/guitar of the phrase's `LofiPreset`) through `LofiSampleBank.add`: attack >= 3 ms (preset.attack 0.003-0.013), hold = note.length, release `preset.release` (0.22-0.36 s), fall^2 envelope, 2-pole smoothing of the sample at 2.15 kHz + 1.75 kHz*brightness (+0.41 kHz*color), pan 0.04, no loop (samples <= 3 s, so a 1.6-beat answer is as long as the piano's natural decay). `LofiSynth.add` has a genuine pad branch for `.texture` (attack 1.35 s, release 2.7 s, 3 detuned partials, pan by midi%5) but is only the fallback when `sample == nil`; changing the pad character means either a new synth path or loop/sustain handling in the sample path.
- Dry lower and upper voices render in separate arrays (`textureLower`, `textureUpper`, `upperShellVoices` l.506) so the mids chain can pan them.
- `LofiStemChains.Mids` (LofiStemChains.swift:99-110, `applyMids` l.332): HPF 160, peak 400 Hz Q1 -3 dB, peak 1.6 kHz Q1 +1.5 dB, LPF 7 kHz; voicePan 0.15 (lower left, upper right, 0.3 apart), mono below 300 Hz (Linkwitz-Riley fold), no compressor.
- Per-phrase level `midsLevel` (LofiRenderer.swift:567): meters lead (after its gain) and mids in 400 Hz-3 kHz (one-pole HP 400, LP 3 kHz) only where both sound (`midsMatchSeconds` 0.1 s min overlap); sets mids `midsUnderLeadDB` = 3.5 dB under the lead, clamped to `midsTrim` 3.6 x/÷ `midsGainRange` 2.5; if overlap is too short uses `midsTrim`; peak ceiling `midsPeakCeiling` 0.6 (-4.4 dBFS). Final texture = mids * midsGain + hiss, edge envelope, then `balance.gain * programTrim` (`LofiPreset.levelDB`). `InstrumentBalance` meters mids at `midsMeterTrim` 0.31 so raising mids does not turn the lead down.
- Wet send: each texture note also renders a second copy into `textureSend` with velocity * note.send (0.45-0.75, no lead-style 0.44 floor, l.118-119) -> `LofiEffects.processReturns` (LofiEffects.swift:100-123): texture feeds the echo (0.37 cross-fed), the Ensemble (0.28), the plate (1.05, same weight as lead), the late room (0.45). Return gains per gesture (cloud/resonance/tape/freeze, l.15-50): the `texture` colour field (0.62-1.33) is in `colors`. Wet stem: `applySpace` HPF 350 Hz, LPF 4.5 kHz, -2 dB @2.5 kHz; `wetGain` 2.7; space duck keyed to lead (4 dB depth, 25 percent sustain share, 100 ms release); `outputTrimDB` -1.5. The granulator also anchors on the first texture note (`LofiEffects.granulate` l.230-258, `mids.first`).
- Chop duck (`ArchiveVoice.MusicDuck`, ArchiveVoice.swift:167): lead -1 dB, mids -1 dB, space -1.5 dB, attack 30 ms, release 300 ms, on featured chops (>= 0.5 s). Applies to the texture fader and wet fader, not bass/drums. Chop chain also leaves low mids to bass/keys/melody (DialogueChopRenderer.swift:325, -4 dB @2.8 kHz tuck, -2 dB @650 Hz).
- Dry texture buffer has no tail/carry: mids stop at the phrase boundary (`midLatestEnd` 14.5). The reverb tail does carry (`Tail`, `fallbackWet`), so a pad's sustained part would have to live in the wet carry or the texture buffer must hold tails (it is n frames; the stem is scheduled back to back).

## 7. What constrains a redesign (summary)
1. Offline, per-phrase, off-audio-thread render; nothing in a realtime path. Each phrase stem is a fixed `n`-frame stereo buffer, sample-accurate, back to back; late-phrase fallback repeats the previous stems. Bass and texture dry stems have no tail: a held pad/bass note ends at the phrase edge (4 ms edge fade) unless the renderer is extended to carry (`Tail` exists only for wet). Notes in score are asserted `beat + length <= 16` (bass) / `<= 14.5` (mids).
2. Drum takes are never altered (no tapering beyond the outer 1 ms/4 ms). Bass attack alignment must keep using `LofiBassVoice.lowRiseLead` + `BassAnchor` (C-B2 median <= 5 ms from audio). Kick duck is bass-only, 4 dB depth (1.5-4.5 dB gate).
3. Routing identity C-B10: five stems + dialogue sum to the bus; no new tap, send or fader unless the analysis and `LofiCaptureHooks` learn it.
4. Low end: only drums and bass own 20-120 Hz (C-B1, test 12 dB). Bass level against drums 60-250 Hz -6..+3 dB. Master 25 Hz HPF; under-25 Hz already warns, so extra sub below 35 Hz is penalised (keep fundamentals >= 40 Hz, and bass register 28...41 MIDI is 41-87 Hz).
5. Mids/lead/chop relationships are gated by C-B5 (3-8 dB under lead, with the 3.39 dB close to the floor), C-B6, C-B8, C-B11, C-B7 (already warn). Pad must come in lower than the shells now in 400 Hz-3 kHz, move energy to 120-300 Hz and above 3 kHz less, and use space carefully: lead minus space is 2.48 dB and wet is already the busiest stem.
6. The mix is currently "nothing jumps out": C-M6 limiter hardly works (mean 0.01 dB), LUFS -12.82 vs ceiling -11.0, true peak -1.20 vs -1.0, so there is about 1.8 LU/0.2 dB of room to add loudness before a gate trips; PLR 11.62 of 12.5.
7. Classic bass voice and legacy tests are frozen: add new voices as new enum cases or tune the three and update `LofiRhythmTests` (loudness match to classic at 1.2 s MIDI 33; 5 cents tuning; click-free).
